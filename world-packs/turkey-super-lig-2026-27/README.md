# Trendyol Süper Lig 2026/27

## Included coverage

- 1 country: Türkiye
- 1 competition: Süper Lig 2026/27
- 18 clubs
- Stable game IDs, display names, home cities, short names and simplified in-game colour pairs
- Provider source mappings in `world-data-sources.json`

## Data source and rights

The season's 18-club participation list is based on the OpenFootball Europe 2026/27 Turkey Süper Lig fixture dataset, published under CC0 1.0. Exact source and licence URLs are recorded in the data manifest.

The source's club-name spellings are preserved as `externalId` values. Display names use the current Turkish names used in the TFF's 2026/27 fixture materials where they differ (for example, Arca Çorum FK, Corendon Alanyaspor and Amed Sportif Faaliyetler).

CC0 applies to the contributed fixture dataset. It does **not** grant third-party trademark rights or rights to official club crests, player photographs, kit artwork, sponsor marks or stadium photographs. This package therefore contains no copied official logos, portraits or kit images. Colour pairs are simplified game metadata, not official kit artwork.

This is not an official TFF, Süper Lig or club licence.

## Roster coverage

No verified real player or staff roster is included yet. The game may generate players using its existing world-generation system. Generated players must not be described as the clubs' real 2026/27 squads.
